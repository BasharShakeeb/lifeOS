## Reference Images

Use all images in the `image` folder as the visual reference.

Do not redesign the UI.
Match the layouts as closely as possible.

## Technical Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui
- Lucide Icons

## Rules

- Reuse components across all pages.
- Keep the Design System consistent.
- Make all pages responsive.
- Use Drawers for Create/Edit.
- Use Modals for Details.
- Do not create extra pages that are not documented.
- Do not add Pricing, Subscription, or Checkout pages.
