# LifeOS - Design System

## Design Philosophy

LifeOS follows a clean, modern, premium productivity design system.

The interface should always feel:

- Minimal
- Elegant
- Fast
- Spacious
- Professional
- Consistent

Every page must look like it belongs to the same application.

Never redesign components differently between pages.

# Shadows

Use soft shadows only.

Avoid strong dark shadows.

Cards should appear floating slightly above the background.

Drawer should have a soft shadow.

Modal should have a stronger shadow than Drawer.

# UI Consistency Rules

Every page must include:

✓ Sidebar

✓ Top Navigation

✓ Search

✓ Filter

✓ Statistics Cards

✓ Main Content

✓ Primary Action Button

✓ Pagination (if needed)

✓ Empty State

✓ Drawer

✓ Detail Modal

All pages must share the exact same spacing, typography, colors, buttons, cards, and interaction patterns.

Never redesign components differently between pages.
